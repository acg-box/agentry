# Privacy

The `gh-settings` and `acg-release` plugins contain instructions only.
They have no executable code, hook, app, MCP server, network client, credential,
or writable runtime state. The plugins do not collect, transmit, or store user
data.

When Codex uses a plugin, Codex can read repository or GitHub settings and run tools
only under the user's request, the target repository's instructions, and the active
Codex environment. ACG Box does not receive that content through these plugins.

Report a privacy concern through the `acg-box/exp` repository issue tracker.
