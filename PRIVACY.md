# Privacy

The `gh-settings` plugin contains instructions only. It has no executable code,
hook, app, MCP server, network client, credential, or writable runtime state. The
plugin does not collect, transmit, or store user data.

When Codex uses the plugin, Codex can read repository or GitHub settings and run tools
only under the user's request, the target repository's instructions, and the active
Codex environment. ACG Box does not receive that content through the plugin.

Report a privacy concern through the `acg-box/exp` repository issue tracker.
