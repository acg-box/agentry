# Automation Development

Automation moved from `itering/exp` to Agentry. Runtime files live under
`plugins/automation`; this directory owns synthetic fixtures, tests, and
benchmark tools. Historical evaluation results remain in the source repository.
The `helixbox/automation-*` schema identifiers remain unchanged for compatibility.
Run `cargo make test-automation` for local verification.

Originally developed in the Helixbox `itering/exp` repository. This migration
preserves the GPL license and runtime behavior. No historical account records,
model transcripts, or evaluation receipts are included.
