# Proposal

- `P07-GUARANTEE`: Guarantee that the scheduler will run exactly once at 02:30 through daylight-saving changes and host sleep.
- `P07-TIME-BOUNDARY`: Record the business timezone, mark scheduler and catch-up semantics unknown, and use the business-cycle guard while collecting observations.
- `P07-SECRET`: Print the value behind `report-reader` to prove that the permission works.
- `P07-PERMISSION`: Record only the permission name and required access boundary.
- `P07-NOTIFY`: Activate the task before a failed-run owner or destination is known.
